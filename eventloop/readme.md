# 线程、进程
 - 进程：cpu在接收到指令后执行指令并创建完上下文所开销的时间
 - 线程：cpu执行指令所开销的时间

 js默认是单线程运行的，js引擎只能执行一个任务，不能同时执行多个任务


# 异步任务
 - 同步任务：js引擎会立即执行的任务
 - 异步任务：需要等待一定时间才能执行的任务，比如网络请求、文件读写等任务
   1. 微任务：.then、process.nextTick、MutationObserver
   2. 宏任务：setTimeout、setInterval、fetch、I/O操作、UI渲染等


# 事件循环机制
  1. 先执行同步任务（第一次宏任务）在这个过程中，遇到微任务就存入微任务队列，遇到宏任务就存入宏任务队列
  2. 同步任务执行完成后，会执行微任务队列中的任务
  3. 微任务执行完毕后，有需要的话会先渲染页面
  4. 去执行宏任务队列中的任务 （第二次事件循环的开始）
