# this 是什么
- 是一个关键字，它提供了一种更优雅的方式传递一个对象的引用，可以让代码更简洁、更易读

# this 可以出现在哪里
1. this 可以出现在全局，就指向 window
2. 函数体内

# this 指向的规则
1. 默认绑定规则---当函数独立调用时，函数中的 this 指向 window
2. 隐式绑定规则---当一个函数被一个对象所拥有并被该对象调用时，函数中的 this 指向调用函数的对象
并且遵循就近原则指向离它最近的对象，而不是离它最近的函数体
3. 显式绑定规则---当一个函数被 call、apply、bind 方法调用时，函数中的 this 指向调用方法的第一个参数
fn.call(fu, x, y)
fn.apply(obj, [x, y])
let foo = fn.bind(obj, x, y)
foo()//fn.bind(obj, x, y)(z)

4. new 绑定规则---当一个函数被 new 关键字调用时，函数中的 this 指向新创建的对象
5. 箭头函数中没有 this 这个概念，写在箭头函数中的 this，指向的是外层函数


# 原型链
- 原型链:v8在查找对象中的属性时，会先查找对象显示拥有的属性，如果没有，就会顺着对象的隐式原型往上走，还找不到，就继续顺着原型链往上走，直到找到null为止
