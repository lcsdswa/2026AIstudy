# 代码执行耗时吗？
- 程序中存在一些耗时的任务，比如：网络请求、定时器等。这些任务我们称之为异步任务

# 异步
- js默认是单线程执行的：意味着同一时间只能执行一个任务。

- 耗时的任务会阻塞后续代码的执行，这样会降低程序的执行效率，所以js设计了一个 事件循环机制 来处理异步任务。

# 处理异步任务
- js会将同步任务执行完毕后，再执行异步任务。而再某种场景下，我们是希望非要某个异步任务执行完毕，才能执行后续代码

1. 回调函数：将后面要执行的函数作为参数传递给前面的异步任务，这就会导致前面的异步函数执行完毕后，才会调用后面要执行的函数

缺点：当异步任务嵌套过多时，会导致回调地狱问题(排查问题困难，代码可读性差，代码维护困难)


# Promise 工作原理
- Promise 是一个对象，它有三种状态：pending、fulfilled、rejected
- pending 状态：初始状态，等待着异步任务的结果
- fulfilled 状态：异步任务执行成功，将结果传递给 then 方法中的回调函数
- rejected 状态：异步任务执行失败，将错误传递传递给 catch 方法中的回调函数
