# 引用类型 （对象类型，复杂类型）

1. object
2. array
3. function
4. date

# v8 是怎么存储不同类型的

1. 基本类型：值直接存储在栈中
2. 引用类型：值存储在堆空间中，但会暴露引用地址，引用地址存储在栈中，引用地址指向堆中存储的对象

# const

1. const 声明的变量如果值是基本类型，那么变量的值是不能被修改的
2. const 声明的变量如果值是引用类型，那么变量的值是不能被修改的，但是只要保证变量对应的引用地址不改变，对象类型的属性是可以被修改的
